# Mon Potager Savoie — PWA

Application de gestion de potager pour la Savoie.

## Déploiement GitHub Pages

Ce dossier contient l'application PWA. Une fois déployé sur GitHub Pages :
- URL : `https://TON-USERNAME.github.io/potager-savoie/`
- Installable comme application Android depuis Chrome

## Mise à jour du nom du dépôt

Si ton dépôt GitHub ne s'appelle pas exactement `potager-savoie`,
ouvre `manifest.json` et `sw.js` et remplace `/potager-savoie/`
par le nom exact de ton dépôt.

Exemple pour un dépôt `mon-jardin` :
- manifest.json : remplacer `/potager-savoie/` par `/mon-jardin/`
- sw.js ligne 3 : remplacer `/potager-savoie` par `/mon-jardin`
